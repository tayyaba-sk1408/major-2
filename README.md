# Veda Technology Website Concept — Day 35

A professional, responsive multi-section business website concept for a technology and digital-services organization. Built with HTML5, CSS3, and vanilla JavaScript.

## Features

- Professional dark navy and cyan visual theme
- Responsive desktop, tablet, and mobile layouts
- Sticky navigation and accessible mobile menu
- Hero section with CSS-created technology illustration
- About and learning-pathway sections
- Program cards and digital-service categories
- Internship and practical-learning section
- Interactive FAQ accordion
- Contact form with client-side validation
- Email draft prepared with a `mailto:` link
- Scroll reveal effects and active-section navigation
- Basic SEO metadata and semantic HTML
- Keyboard support and reduced-motion consideration
- No framework, database, or build tools required

## Technologies

- HTML5
- CSS3
- JavaScript
- Google Fonts (optional internet connection)
- Git and GitHub (optional)

## How to Run

1. Extract the project folder.
2. Open it in Visual Studio Code or another editor.
3. Open `index.html` in a modern browser.
4. Optional: install the VS Code Live Server extension, right-click `index.html`, and choose **Open with Live Server**.
5. Resize the browser or use developer tools to test mobile and tablet layouts.

No package installation or backend server is required.

## Customize

- Edit section text and content in `index.html`.
- Change colors, spacing, typography, and breakpoints in `style.css`.
- Update menu, FAQ, and form behavior in `script.js`.
- Replace example categories with accurate, approved organization information.
- Add official social links, verified contact details, and authorized logo assets when available.

## Important Accuracy Note

This is a learning and demonstration website concept. Program areas, service categories, and internship content are illustrative examples, not a verified list of current Veda Technology offerings. Confirm public information with the organization before publishing. Do not add unsupported certifications, approvals, fees, placement guarantees, or service claims.

The contact form does not submit data to a backend and does not store information. After validation, it attempts to open the visitor's default email application with a `mailto:` link. The visitor must review and send the email. For a production website, connect the form to an approved secure backend or contact-form service and include an appropriate privacy notice.
